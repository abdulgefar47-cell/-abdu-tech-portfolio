# Abdu Tech — Personal Portfolio

A responsive single-page portfolio for Getahun.

## Features
- Responsive mobile, tablet, and desktop layout
- About, skills, projects, and contact sections
- Mobile navigation menu
- Dark technology-inspired design
- No build tools or dependencies required

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. GitHub will provide the published website URL.

Update the project entries and contact details in `index.html` as your work grows.
